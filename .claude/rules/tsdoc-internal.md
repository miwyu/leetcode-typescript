# TSDoc の記述規約 - 内部アルゴリズム実装

各実装ファイルには、以下の仕様に従って日本語で詳細な TSDoc コメントを記述する必要があります。

焦点: **どのように動作し、なぜそうするのか** - 学習とメンテナンスのため

- タイトル形式: `[問題名] - [アプローチ名（日本語）]による実装`
- アプローチとそのトレードオフを説明する簡潔な概要（日本語で1〜2行）
- `@remarks` セクションでアルゴリズムと計算量の詳細分析を記述:
  - アルゴリズムの手順（番号付き、日本語）
  - 時間計算量: O 記法と詳細な計算の内訳（日本語）
    - ループの反復回数と操作を説明
    - 数学的導出を示す（例: n(n-1)/2 → O(n²)、n × O(1) = O(n)）
  - 空間計算量: O 記法とメモリ使用量の説明（日本語）
    - 使用するデータ構造を記述
    - 最悪ケースのメモリ増加を説明
- `@throws` タグは関数が実際に例外をスローする場合のみ追加（日本語）
- `@internal` タグを付与

構造の例:

```typescript
/**
 * Two Sum - 総当たり法による実装
 *
 * 全ての組み合わせをチェックする非効率的なアプローチ。
 *
 * @remarks
 * アルゴリズム:
 * 1. 外側のループで各要素を走査
 * 2. 各要素に対して、後続の全ての要素をチェック
 * 3. 合計が目標値と一致したらインデックスを返す
 *
 * 時間計算量: O(n²)
 * - 外側のループ: i = 0 から n-2 まで → (n-1)回実行
 * - 内側のループ: j = i+1 から n-1 まで
 *   - i=0のとき: (n-1)回
 *   - i=1のとき: (n-2)回
 *   - ...
 *   - i=n-2のとき: 1回
 * - 合計:
 *   (n-1) + (n-2) + ... + 1 = n(n-1)/2
 *   = (n² - n)/2
 *   → O(n²)
 *
 * 空間計算量: O(1)
 * - ループ変数 i: 1個
 * - ループ変数 j: 1個
 * - 一時変数: 入力サイズnに依存しない → 定数個(c)
 * - 合計: 1 + 1 + c → O(1)
 *
 * @throws 合計が目標値と一致するペアが見つからない場合はエラー
 *
 * @internal
 */
```
